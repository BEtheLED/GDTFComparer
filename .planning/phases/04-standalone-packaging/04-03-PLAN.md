<objective>
Write the first-launch instructions that let a non-technical lighting/AV user get past macOS Gatekeeper and Windows SmartScreen for this one unsigned app, safely. This is PKG-03's "otherwise configured" path, chosen in D-01. The instructions go in two places: the README, where people land, and the GitHub Release description, where people download. A test keeps both correct and keeps them from ever turning into "switch your security off" advice.

Purpose: PKG-03 and ROADMAP Phase 4 success criterion 3. D-01: ship unsigned with clear one-time bypass instructions. The macOS steps use the current System Settings flow, because the right-click shortcut D-01's wording assumed no longer exists (RESEARCH Pitfall P1).
Output: README.md "Download and run (no Python needed)" section, packaging/release-notes.md, tests/test_release_docs.py.

Scope: documentation only. No file under src/ changes, no in-app message is added, and the deferred license change is not touched.
</objective>
