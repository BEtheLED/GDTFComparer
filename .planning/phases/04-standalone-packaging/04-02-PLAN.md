<objective>
With the user's explicit go-ahead, move the build onto GitHub's own macOS and Windows machines (D-02). After this plan, every push of a version tag automatically builds both apps, launches each zipped download to prove it opens, and publishes both as one GitHub Release (D-03, D-04). A hand-started run does everything except publish, which lets Claude test the whole pipeline here without releasing anything yet.

Purpose: PKG-01 and PKG-02 for anyone, not just the creator. The builds come from a clean, repeatable CI run on each OS, not from one person's computer. PyInstaller can't build for another OS (RESEARCH, STACK.md), so CI is the only way this Mac can produce the Windows download.
Output: .github/workflows/release.yml, proven by a green hand-started run whose downloads pass the smoke check, plus any Windows-only fixes to packaging/app.spec or packaging/smoke_check.py.
</objective>
