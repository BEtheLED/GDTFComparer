<objective>
Gap closure for three non-blocking code-review findings, each cheap enough to fix now rather than defer:
- WR-02: the user can no longer compare a file against itself. Adding the target as a comparison is refused, and picking a listed comparison file as the new target removes it from the list. Both cases say so in the status bar, so the user never gets a misleading "nothing differs" table.
- IN-01: the two unused public members (`ComparisonRow.any_differs`, `OsThemeFollower.current_theme`) are confirmed as intended surface. `any_differs` is the row predicate that Phase 2 diff highlighting (DIFF-01) and Phase 3 diff-only export (EXPORT-02) need, and `current_theme` is part of 01-05's published `OsThemeFollower` interface. Both are now covered by tests.
- IN-02: the README states the real Python floor.

Purpose: WR-02 is a friendly-feedback-on-a-bad-selection behaviour in the RELI-01 family: an invalid file choice produces a clear message instead of a silently wrong result. IN-01 and IN-02 are hygiene with no requirement of their own.
Output: guarded `MainWindow.add_compare_files` / `set_target_file`, new tests/gui/test_file_selection.py and tests/core/test_models.py, one new theme test, and corrected README setup commands.
</objective>
