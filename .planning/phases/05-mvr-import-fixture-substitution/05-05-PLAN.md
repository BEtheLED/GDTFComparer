## Phase Goal

**As a** lighting designer, **I want to** import an MVR show file, mark which attributes matter most for each fixture type, and share those requirements, **so that** anyone, including a rental shop checking their own inventory, can find substitute fixtures that meet them.

This plan's slice: "can find substitute fixtures that meet them". The shop's side, read in their terms: the user asked for "green meets or is better (note some fields might be lower is better), yellow it's close so it might work, red way outside the set range will not work."
